# Sherpas brand assets

Original Sherpas wordmark extracted from https://sherpaswealth.com/ on 17 November 2026 for the Sherpas Pulse project. Light variant changes only its fill colour. Sherpas retains its trademark.

Poppins by Indian Type Foundry and Inter by Rasmus Andersson, downloaded from Google Fonts. Both use the SIL Open Font License, version 1.1. Fonts are served locally; no third-party font requests at runtime.
